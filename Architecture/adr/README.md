# Architecture Decision Records

ADR 用來記錄會影響多個模組、難以回復，或需要保存決策原因的架構選擇。

## ADR 清單

- [ADR-0001 Documentation-first baseline](ADR-0001-documentation-first.md) — `Accepted`

## 建立規則

每份 ADR 至少包含：

- Status
- Context
- Decision
- Alternatives considered
- Consequences
- Related documents

ADR 不用來記錄一般實作細節、暫時除錯筆記或單純的 TODO。編號只遞增、不重用。
