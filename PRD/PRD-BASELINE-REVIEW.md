# PRD Baseline Review

狀態：`Superseded — historical v1.0 review`

## 1. Purpose

This file preserves the original PRD v1.0 document review. It evaluated the earlier `FR-001`–`FR-011` and `NFR-001`–`NFR-013` baseline before the Repository owner explicitly defined the current resident PrintScreen、multi-display、Editing／Annotation and PNG Save workflow.

It is retained for history only.

## 2. Supersession

The following current sources supersede this review:

1. [PRD-0004 Core Workflow](PRD-0004-core-workflow.md) — Accepted v1.1
2. [PRD-0005 Functional Requirements](PRD-0005-functional-requirements.md) — Accepted v1.1
3. [PRD-0006 Non-functional Requirements](PRD-0006-non-functional-requirements.md) — Accepted v1.1
4. [PRD Freeze Review](PRD-FREEZE-REVIEW.md) — current product acceptance
5. [Requirements-to-Code Conformance Matrix](PRD-TRACEABILITY-MATRIX.md) — current implementation gap authority

Where the original review conflicts with these sources, the current sources are normative.

## 3. Historical Scope

The original review confirmed document structure for an earlier capability-level baseline but did not define the current requirements for:

- background residency and user-controlled PrintScreen takeover;
- all-display Frozen Virtual Desktop;
- cross-monitor rectangular selection;
- locked-selection movement、resize and reselection;
- mandatory Editing／confirmation;
- required v1 Annotation tools and Undo／Redo;
- explicit Complete and Save commitments;
- Windows Save As、PNG plus Clipboard;
- recoverable Editing preservation and focus restoration.

The absence of these requirements in the original review must not be interpreted as current scope exclusion.

## 4. Historical Value

This file remains useful only to explain how the Repository’s initial documentation baseline was assessed before the v1.1 product correction. It is not an implementation input and should not be included in routine Codex reading sets.
