# Research Glossary

狀態：`Accepted`

本表只建立研究時使用的共通名詞，不在此定義 SnipPlus 的產品行為。

| Term | 中文 | Research 使用範圍 |
| --- | --- | --- |
| Overlay | 覆蓋層 | 研究畫面上覆蓋於其他內容之上的視覺層。 |
| Capture | 擷取 | 研究工具取得畫面或內容的外部行為；不代表 SnipPlus 已採用。 |
| Annotation | 註記 | 研究在結果上增加標記、圖形或文字的能力。 |
| Clipboard | 剪貼簿 | 研究內容如何複製、貼上或交付。 |
| Selection | 選取 | 研究使用者指定來源或範圍的行為。 |
| Callout | 標註框 | 研究用於指出內容的文字或圖形元素。 |
| Step Number | 步驟編號 | 研究用於標示順序的註記元素。 |
| OCR | 光學字元辨識 | 研究工具是否能從影像取得文字，以及觸發與輸出方式。 |
| Reverse Research | 反向研究 | 從可觀察產品行為建立來源與流程記錄，不等同於複製設計。 |
| Source of Truth | 事實來源 | 在本 Repository 中指有來源、版本與驗證資訊的外部觀察。 |
