## Historical status rule

The numbered Research files preserve the status that was correct when they were written. Statements such as `Host Framework unresolved`、`Rendering Decision not made` or `Execution not authorized` are historical boundaries and are not rewritten after a later ADR.

## Runtime evidence

Research plans do not become runtime evidence. Actual restore、build、capture、rendering、Clipboard and cleanup evidence must be generated by the explicitly authorized implementation task and stored in a separate evidence boundary.

## Anti-proliferation boundary

- Do not create document 81 or any same-pattern prerequisite／reassessment／authorization／closure extension.
- Do not add another Rendering or Capture readiness chain.
- A verified implementation conflict may create one targeted evidence/result record or corrective ADR.
- Research does not override Frozen PRD／Specs／Architecture or Accepted ADRs.
- This directory must not become a source-code or prototype directory.
