## Scope boundary

本階段只記錄外部可觀察的操作流程、狀態轉換、使用者操作與系統反應；不研究 UI 外觀、不比較其他產品、不提出 SnipPlus 改善方案。

## Research boundary

研究開始前必須先確認 Windows 版本、Snipping Tool 版本、研究日期、來源與驗證方式。無法確認的內容標示 `UNKNOWN`，不得依記憶補完。
