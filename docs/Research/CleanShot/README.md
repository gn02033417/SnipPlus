# CleanShot Research

狀態：`Proposal`

本入口只定義未來 CleanShot 相關研究主題，不包含產品事實或 SnipPlus 設計。

## Planned topics

- Capture workflow
- Overlay and selection behavior
- Annotation and editor behavior
- Clipboard, export and sharing
- Recording or advanced capture modes
- Platform and licensing limitations

正式研究前需依 [source policy](../source-policy.md) 建立來源與驗證記錄。
